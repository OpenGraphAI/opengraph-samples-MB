Install

Install via MCP

Add the OpenGraph AI image MCP server to your client of choice. Requires pip install opengraph-image and an ANTHROPIC_API_KEY in your environment.

Claude Desktop

~/Library/Application Support/Claude/claude_desktop_config.json

{
  "mcpServers": {
    "opengraph-image": {
      "command": "opengraph-image-mcp",
      "env": {
        "ANTHROPIC_API_KEY": "your-api-key-here"
      }
    }
  }
}
